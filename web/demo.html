MLFont Sliced Webfonts — Live Browser Demo

This page uses Noto Sans SC Sliced (30,759 Simplified Chinese codepoints partitioned into 102 machine-learning co-occurrence slices). Instead of downloading the full 8.89 MB WOFF2 font file, your browser inspects the characters rendered below via CSS unicode-range and only downloads the small .woff2 slices required for this page.

示例文本 (Sample Rendered Text)

汉字作为一种语素文字，其每个单一字符都拥有具体的表意。因此，有些字符同时出现在同一页面上的概率会高于另一些字符。 我们通过机器学习算法对网页内容进行主题建模与区间紧凑化遗传算法优化，将整套中文字体切分为静态子集切片， 使得浏览器只需按需下载当前页面所需的少量 WOFF2 切片即可极速渲染完整字库。（点击此处可直接编辑输入任意生僻字，如：龘、龖、𰻝！）
